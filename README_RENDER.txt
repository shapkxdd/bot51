RISBOT 51 — Render

Build Command:
pip install -r requirements.txt

Start Command:
python bot.py

Environment Variable:
BOT_TOKEN = токен бота

Важно: бесплатный Render может останавливать сервис после простоя. bot_data.json хранится на эфемерной файловой системе бесплатного сервиса и может сброситься после перезапуска/переразвертывания.
